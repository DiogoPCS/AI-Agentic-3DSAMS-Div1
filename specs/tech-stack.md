# Stack Técnica

- **Linguagem:** TypeScript no frontend e no backend.
- **Frontend:** React com Vite para a aplicação web.
- **API:** Node.js com Express, em serviço separado do frontend.
- **Comunicação:** API REST com respostas JSON.
- **Banco de dados:** SQLite na fase inicial.
- **Conteúdo:** Cursos, matrizes curriculares e notícias devem ser servidos pela API; notícias são gerenciadas por usuários autenticados.
- **Compatibilidade:** Layout responsivo e suporte a navegadores modernos.

Manter a separação entre interface, API e persistência para permitir evolução sem acoplar o catálogo a uma tecnologia específica de armazenamento.
