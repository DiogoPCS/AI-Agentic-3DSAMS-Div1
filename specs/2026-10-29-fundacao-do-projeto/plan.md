# Plano: Fundação do projeto

## Grupo 1 — Estrutura

1. Criar a estrutura separada para frontend React/Vite e API Node.js/Express.
2. Configurar TypeScript nos dois serviços.
3. Adicionar configurações e scripts necessários para desenvolvimento local.

## Grupo 2 — Persistência e integração

1. Configurar a API REST com respostas JSON.
2. Preparar a conexão inicial com SQLite.
3. Adicionar uma verificação simples de disponibilidade da API e do banco.

## Grupo 3 — Uso e entrega

1. Documentar pré-requisitos e comandos para iniciar os serviços.
2. Executar frontend e API localmente e corrigir falhas encontradas.
3. Registrar os resultados em `validation.md` antes de solicitar merge.
